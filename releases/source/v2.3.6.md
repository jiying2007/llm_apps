# Jingdu v2.3.6 Source Release

version: v2.3.6
kind: source-release
google_play_production: false

This patch release carries the immutable-release governance and Reader hot-path hardening accumulated after v2.3.5. New source releases are prepared as annotated tags plus draft GitHub Releases only after the existing product gates pass; APK, checksum, and signing-certificate evidence are attached while the draft is mutable, and a separate successful exact-main finalizer publishes only a fully populated release. Already-published immutable releases remain side-effect-free.

Reader execution is also tightened without changing user-visible pagination or selection semantics: paged mode avoids full-window selection prewarm, identity source/display projections avoid unnecessary page-sized mapping-array allocation, the current-page StaticLayout path reuses the latest snapshot in O(1), and normal identity presentation avoids unnecessary regex/string replacement work. Continuous exact-selection prewarm remains worker-bound.
