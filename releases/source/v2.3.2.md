# Jingdu v2.3.2 Source Release

version: v2.3.2
kind: source-release
google_play_production: false

This patch release publishes the current GitHub Android release stage from a newly gated immutable source commit. It includes the Reader display-only text fast path that avoids unnecessary source/display offset projection when only converted display text is required, plus the release-governance alignment that defines the repository-stable Android generic debug key (`androiddebugkey`) APK as the official installable artifact for this stage.

The GitHub Release for this tag must include `Jingdu-v2.3.2-debug-signed.apk`, `SHA256SUMS.txt`, and `SIGNING-CERT-SHA256.txt`. The APK is built from the immutable `v2.3.2` source tag and signed with the repository-stable Android debug key. `main` branch protection / repository rulesets are not required for this release stage.

This is not Google Play production signing or rollout evidence. Google Play production remains a separate future stage using the production/upload signing path and the external Play Console / physical-device evidence documented in `docs/PRODUCTION_READINESS.md`.
