# Jingdu v2.3.4 Source Release

version: v2.3.4
kind: source-release
google_play_production: false

This patch release restores reliable natural horizontal swipe paging in paged reading while explicitly yielding to active native text selection, separates horizontal paging intent from the left-edge brightness gesture, and removes heavy haptic feedback from ordinary page turns.

Reader chrome is refined around a lightweight floating header and an always-visible direct-scrub progress dock with a 48dp touch target, adaptive chapter ticks, chapter-aware progress accessibility semantics, compact skim feedback, responsive content width, and a focused Quick Settings surface. The Reader regression suite covers natural 700ms swipes, vertical brightness arbitration, direct progress scrubbing, accessible `SetProgress`, chapter lookup boundaries, and adaptive width policy.

Paged reading performance is hardened without changing the checked-in benchmark definitions, SLO thresholds, or baselines. Ordinary page turns avoid full-page SLIDE layout work on the hot path, and the 64 KiB Reader page cache now uses a sparse Unicode-safe code-point-to-UTF-16 index so page-window slicing scans only a bounded small stride instead of rescanning from the window start on every page turn.

The GitHub Release for this tag must include `Jingdu-v2.3.4-debug-signed.apk`, `SHA256SUMS.txt`, and `SIGNING-CERT-SHA256.txt`. The APK is built from the immutable `v2.3.4` source tag and signed with the repository-stable Android debug key (`androiddebugkey`) used for the current GitHub release stage. `main` branch protection / repository rulesets are not required for this release stage.

This is not Google Play production signing or rollout evidence. Google Play production remains a separate future stage using the production/upload signing path and the external Play Console / physical-device evidence documented in `docs/PRODUCTION_READINESS.md`.
