# Jingdu v2.3.5 Source Release

version: v2.3.5
kind: source-release
google_play_production: false

This patch release publishes the product-maturity work accumulated after v2.3.4. Reader layout and continuity are hardened with Smart Layout, CJK-aware phrase line breaking, visual-center source-anchor restoration, reusable reading presets, system reduced-motion behavior, and foldable book-posture handling while preserving the existing performance contract.

Reading and library quality are further tightened through TTS pronunciation overrides, stronger TXT structure recognition, 200% font-scale UI coverage, production-facing error-code and private-file handling contracts, lifetime Pro entitlement validation, and an expanded 650-row Smart Clean evidence matrix. Native packaging remains covered by the 16 KiB page-size gate, and the Android functional path keeps local-asset and accessibility-oriented smoke coverage.

The release does not change checked-in Macrobenchmark definitions, performance SLO thresholds, performance baselines, or dependency versions. The exact pre-release `main` SHA `d01ce5002215cb09c03db8bbcabc1627272a0006` passed CI #1177 on attempt 1, including R8 Macrobenchmark `OK (5 tests)`, Baseline Profile `OK (2 tests)`, page-turn P95/P99 `59.603/70.202ms`, continuous-scroll P95/P99 `38.408/56.998ms`, and Chapters/Settings P95/P99 `77.879/96.163ms`. The performance evidence artifact is `9961152312` with SHA256 `e16d1de7744546803e92e339350f9ff3b79af10108d7493d3a8ae7eb67beb466`.

The GitHub Release for this tag must include `Jingdu-v2.3.5-debug-signed.apk`, `SHA256SUMS.txt`, and `SIGNING-CERT-SHA256.txt`. The APK is built from the immutable `v2.3.5` source tag and signed with the repository-stable Android debug key (`androiddebugkey`) used for the current GitHub release stage. `main` branch protection / repository rulesets are not required for this release stage.

This is not Google Play production signing or rollout evidence. Google Play production remains a separate future stage using the production/upload signing path and the external Play Console / physical-device evidence documented in `docs/PRODUCTION_READINESS.md`.
