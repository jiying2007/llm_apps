# Jingdu v2.3.3 Source Release

version: v2.3.3
kind: source-release
google_play_production: false

This patch release restores a guaranteed manual paging path for paged reading, broadens physical-key paging to common DPAD/Page keys while preserving the configured volume-key policy, and simplifies the bottom Reader chrome by keeping the precise seek slider collapsed until the reader explicitly opens it from the compact progress percentage.

The GitHub Release for this tag must include `Jingdu-v2.3.3-debug-signed.apk`, `SHA256SUMS.txt`, and `SIGNING-CERT-SHA256.txt`. The APK is built from the immutable `v2.3.3` source tag and signed with the repository-stable Android debug key (`androiddebugkey`). `main` branch protection / repository rulesets are not required for this release stage.

This is not Google Play production signing or rollout evidence. Google Play production remains a separate future stage using the production/upload signing path and the external Play Console / physical-device evidence documented in `docs/PRODUCTION_READINESS.md`.
